# سیستم طراحی و «قانون رنگ» — کلینیک تهران لیزر

سند مرجع رنگ، تایپوگرافی و توکن‌های طراحی. **منبع یگانهٔ حقیقت (single source of truth): `src/styles/tokens.css`** — هر رنگ، فاصله، شعاع، سایه و انیمیشن از همین فایل می‌آید. هیچ مقدار رنگ تازه‌ای نباید پراکنده در صفحات تعریف شود.

---

## ۱. هویت بصری

- **سبک:** لوکس تیره «اُبسیدین–طلایی» (Obsidian–Gold) با نظام برجستگی سه‌بعدی (3D bevel) در `tokens.css` و `components-3d.css`.
- **زبان/جهت:** `fa-IR` و `dir="rtl"` روی `<html>`.
- **فونت:** `Vazirmatn Variable` (`@fontsource-variable/vazirmatn`) — متغیر `--font-sans`.
- **خانواده‌ها:** سطح روشن (ivory/white) + سطوح تیره (obsidian) — هر دو مجاز، اما **روابط رنگ محدودند** (بخش ۳).

## ۳. قانون رنگ (The Colour Law)

> **قانون طلایی:** فقط **متن روشن روی پس‌زمینهٔ تیره** یا **متن تیره روی پس‌زمینهٔ روشن**.
> هر جفت متن/پس‌زمینه باید حداقل **۴.۵:۱** (سطح AA) باشد؛ برای متن بزرگ (≥۲۴px، یا ≥۱۸.۶۶px بولد) حداقل **۳:۱**.

### ۳.۱ ماتریس مجاز (طبق CONTRACT)

| نقش | توکن | مجاز روی |
| :--- | :--- | :--- |
| متن اصلی | `--on-ink` `#f7f3ec` | سطوح اُبسیدین |
| متن کم‌رنگ | `--on-ink-muted` `#b3aa9c` | سطوح اُبسیدین (کنتراست ≥۴.۵ را تأیید کنید) |
| متن اصلی | `--color-ink` `#16130f` | سطوح ivory/سفید |
| متن ثانویه | `--color-text-secondary` `#6b6459` | سطوح ivory/سفید |
| متن تأکیدی | `--gold-400` `#f5d77f` | **فقط اُبسیدین** |
| متن تأکیدی | `--color-primary-strong` `#876c3c` | **فقط ivory** |
| پرکنندهٔ طلایی | `--gold-500` `#d4af37` | **فقط به‌عنوان پرکننده** → متنی که رویش می‌نشیند باید `--color-ink` باشد |

### ۳.۲ ترکیب‌های ممنوع (BANNED)

| # | ترکیب ممنوع | دلیل |
| :--- | :--- | :--- |
| ۱ | **متن طلایی روی پرکنندهٔ طلایی** | کنتراست نزدیک ۱:۱ — متن عملاً ناپیدا |
| ۲ | **متن روشن/سفید روی ivory** | سفید روی `#faf8f5` |
| ۳ | **متن تیره روی اُبسیدین** | تقریباً سیاه روی تقریباً سیاه |
| ۴ | **خاکستری `#cbd5e1` روی سفید** | زیر آستانهٔ ۴.۵:۱ |

### ۳.۳ چرا این قانون وجود دارد (دادهٔ واقعی)

کنتراست روی سایت **زنده** اندازه‌گیری شد و **۳۶ نقص کنتراست** (۲۱ سلکتور یکتا) روی صفحهٔ `/` یافت شد — نه یک ایراد سلیقه‌ای، بلکه متنی که واقعاً خوانده نمی‌شد:

| نمونه | نسبت اندازه‌گیری‌شده | نتیجه |
| :--- | :--- | :--- |
| متن طلایی `#f5d77f` روی پرکنندهٔ طلایی `#d4af37` | **۱٫۴۹:۱** | تقریباً ناپیدا (`.announcement-link`, `.hero-badge`, `.discount-tag`, `.testi-author .author-avatar`) |
| متن تقریباً سیاه `#07090e` روی اُبسیدین `#0a0b0d` | **۱٫۰۱:۱** | کاملاً ناپیدا (`.btn span`, `.promo-badge-ribbon span`) |
| متن سفید `#ffffff` روی ivory `#faf8f5` | **۱٫۰۶:۱** | کاملاً ناپیدا (`.section-title`, `.male-title`, `.location-heading`) |
| خاکستری `#cbd5e1` روی سفید `#ffffff` | **۱٫۴۸:۱** | ناخوانا (`.duration-badge span`) |
| `.old-price .strikethrough` روی اُبسیدین | **۴٫۱۱:۱** | زیر آستانهٔ ۴٫۵ |

هدف این پوش: **۰ نقص روی `/`** (و حداکثر ۲ نقص در سایر صفحات عمومی)، اندازه‌گیری‌شده در دو ویوپورت ۳۹۰px و ۱۴۴۰px.

### ۳.۴ روش سنجش کنتراست

اسکریپت سنجش، رنگ مؤثر پس‌زمینه را با پیمایش والدین (`getComputedStyle().backgroundColor`) پیدا می‌کند، نسبت `(L1+0.05)/(L2+0.05)` را از لومینانس نسبی WCAG حساب می‌کند و آستانه را بر اساس اندازه و وزن فونت (۳:۱ یا ۴٫۵:۱) انتخاب می‌کند. جزئیات کامل در `CONTRACT.md` بخش «The contrast audit script».

## ۴. قواعد پیاده‌سازی

- **رنگ تزئینیِ بی‌معنا ممنوع:** هر رنگی باید یک نقش معنایی (وضعیت، سطح، تأکید) داشته باشد، نه صرفاً دکور.
- **الگوهای دکمهٔ طلایی:** گرادیان‌های `--gradient-gold-btn` در `tokens.css` طوری تیره‌سازی شده‌اند که متن روی دکمه به AAA (≥۷:۱) برسد.
- **`color-scheme: dark light`** روی `:root` تنظیم شده است.
- **تغییر توکن = تغییر سراسری:** یک اصلاح در `tokens.css` همهٔ صفحات را هم‌زمان درست می‌کند؛ همین دلیل یگانه بودن منبع است.
