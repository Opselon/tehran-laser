# کلینیک تخصصی تهران لیزر (Tehran Laser)

> پلتفرم جامع دیجیتال، سامانه رزرواسیون آنلاین ضد هم‌پوشانی (Double-Booking Safe) و مرکز فرماندهی عملیات کلینیک تهران لیزر در منطقه پاسداران.

مبتنی بر معماری ابری **Cloudflare Workers (workerd)**، پایگاه داده توزیع‌شده **Cloudflare D1**، چارچوب رندرینگ سمت سرور **Astro SSR (v5)**، جزایر تعاملی **React**، سیستم طراحی لوکس اختصاصی (Vanilla CSS Tokens) و زبان برنامه‌نویسی **TypeScript Strict**.

## ۲. پشته فناوری (Technology Stack)

| لایه | فناوری انتخابی | دلیل انتخاب و انطباق با استاندارد |
| :--- | :--- | :--- |
| **Runtime** | Cloudflare Workers (`workerd`) | بدون سرور (Serverless)، اجرای فوق‌سریع در لبه، سازگار با استاندارد Web APIs |
| **Database** | Cloudflare D1 (SQLite Engine) | تراکنش‌های همگام، شاخص‌گذاری بهینه، آماده‌سازی پرسمان‌ها (Prepared Statements) |
| **Framework** | Astro 5 SSR (`output: 'server'`) | تحویل HTML خالص برای موتورهای جستجو و حذف وابستگی به جاوااسکریپت در صفحات عمومی |
| **Interactive Islands** | React 19 (`client:load`) | تعامل سریع در جادوگر رزرو ۶ مرحله‌ای و داشبورد مدیریتی |
| **Validation** | Zod (v3) | اعتبارسنجی سخت‌گیرانه در مرزهای ورودی API و فرم‌های عمومی |
| **Security** | WebCrypto API (PBKDF2-SHA256) | رمزنگاری پسورد با ۱۰۰٬۰۰۰ دور تکرار و سالت تصادفی، سشن‌های سروری SHA-256 |
| **Calendar** | `jalaali-js` | نمایش تقویم جلالی (شمسی) برای کاربران ایرانی با ذخیره‌سازی استاندارد UTC ISO-8601 |
| **Testing** | Vitest + `@cloudflare/vitest-pool-workers` | تست واحد و تست‌های یکپارچگی روی موتور واقعی D1 / Miniflare |

## ۳. دستورات اجرایی و توسعه (CLI Commands)

```bash
# نصب وابستگی‌ها
npm install

# همگام‌سازی تایپ‌های استرو و بررسی تایپ‌اسکریپت
npm run typecheck

# اجرای تست‌های واحد و یکپارچگی D1
npm test

# اجرای تست‌های یکپارچگی workerd به تنهایی
npm run test:integration

# بیلد نهایی سرور برای Cloudflare Workers
npm run build

# اجرای محلی سرور توسعه
npm run dev

# ساخت تایپ‌های محیطی کلودفلر
npm run cf:types
```

## ۴. ساختار مخزن پروژه

```text
TehranLasser/
├── migrations/             # مایگریشن‌های ترتیبی دیتابیس D1 (0001 تا 0005)
├── src/
│   ├── components/         # جزایر ری‌اکت (BookingWizard, AdminDashboard)
│   ├── db/                 # هلپرهای کوئری D1 و prepared statements
│   ├── domain/             # مدل‌های پایه، وضعیت رزرو، اعتبارسنجی Zod و DTOها
│   ├── layouts/            # قالب‌های پایه (PublicLayout, AdminLayout)
│   ├── lib/                # تقویم جلالی، سکیوریتی PBKDF2، سشن کوکی، کلاینت API
│   ├── pages/              # صفحات عمومی SSR، پنل ادمین و روتر /api/v1
│   ├── server/             # لایه ریپازیتوری دیتابیس، رزرو اتمیک، احراز هویت RBAC
│   └── styles/             # توکن‌های دیزاین سیستم لوکس، ریست پایه و استایل ادمین
├── tests/
│   ├── unit/               # تست‌های واحد قیمت‌گذاری، در دسترس بودن، اسلات‌ها، جلالی
│   └── integration/        # تست‌های یکپارچگی D1، مسابقه همزمانی رزرو، RBAC و لاگین
├── docs/                   # مستندات کامل API
├── ARCHITECTURE.md         # مستند معماری سامانه
├── DATABASE.md             # مستند جداول، شاخص‌ها و سیاست کوئری D1
├── SECURITY.md             # مدل تهدیدات امنیتی و سیاست سشن‌ها
├── DEPLOYMENT.md           # راهنمای استقرار روی Cloudflare Workers
└── wrangler.jsonc          # پیکربندی دپلوی Wrangler و بایندینگ‌های D1
```
